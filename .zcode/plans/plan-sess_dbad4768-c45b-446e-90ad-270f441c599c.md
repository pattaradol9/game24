# เว็บเกม 24 — Plan สมบูรณ์ (Final v12) — เริ่มลงมือทำเวอร์ชันแรก

## ภาพรวม
เกม 24 การ์ตูนสไตล์เว็บเกม · Single + Multiplayer ห้องเพื่อนเรียลไทม์ · Anonymous เล่นได้, สะสมต้อง Sign in with Google · server แจกไพ่+ตรวจเฉลยเอง · Tink + Cloud KMS · 4 โหมด JACK/QUEEN/KING/ACE · Tier อิง Level (Master = Lv.100) + โบนัสโควตาตัวช่วยเฉพาะ Single

## ระบบ Level และ Tier
- Level: cumulative EXP ถึง Lv.n = 30×(n−1)×n (Lv.100 = 297,000) คำนวณ runtime จาก total_exp · cosmetic Lv.5/10/25 · ป้าย LEVEL UP!
- Tier = floor((Level−1)/20): Bronze Lv.1 / Silver Lv.20 (11,400) / Gold Lv.40 (46,800) / Platinum Lv.60 (106,200) / Diamond Lv.80 (189,600) / Master Lv.100 (297,000)
- โบนัสโควตาตัวช่วย (เฉพาะ Single): Bronze/Silver +0, Gold/Platinum +1, Diamond/Master +2 → hint ต่อมือ 1/1/2/2/3/3 · ข้ามไม่จำกัด
- Multiplayer: โควตาทุกคนเท่ากัน (host ตั้ง) ไม่เกี่ยว Tier · tierUp/levelUp แจ้งสดทุกครั้งที่ขึ้นขั้น · ไม่มีการลดขั้น
- EXP รายโหมด (player_mode_stats) ใช้จัด Leaderboard แยกโหมด

## โหมดความยาก
JACK 1–10 เลขเต็มล้วน 120 วิ ×1 · QUEEN 1–13 คลาสสิก 90 วิ ×2 · KING 1–13 บังคับเศษส่วน 75 วิ ×3 · ACE 1–19 เศษส่วน+เฉลยเดียว 60 วิ ×5 · EXP = (10+วิที่เหลือ)×multiplier, streak ≥3 +10×multiplier

## Envelope Encryption
`system_keys` 1 แถว = {wrapped Tink keyset AES256-GCM, hash_salt} ห่อด้วย Cloud KMS · start → unwrap ครั้งเดียวถือใน memory จน restart (fail-closed) · `ENCRYPTION_MODE=kms|local` (fakekms สำหรับ dev/test) · AD ทุก ciphertext · เข้ารหัส token/email/google_sub/nickname/picture · `token_hash`/`sub_hash` + salt ใน blob · rotation ด้วย multi-key keyset + CLI re-encrypt

## DB / API
- SQLite (modernc, CGO=0): players (+total_exp), player_mode_stats (player_id,mode UNIQUE), rounds (single), system_keys — ห้องไม่ persist
- REST /api/v1 (envelope {success,message,data,errors}): POST /players, POST /auth/google, GET /me, POST /rounds {mode}, POST /rounds/{id}/submit|skip|hint, GET /leaderboard?mode=, POST /rooms, GET /rooms/{code} — เกมในห้องผ่าน WS
- Env: GOOGLE_OAUTH_CLIENT_ID (ไม่ตั้ง = guest เท่านั้น), KMS_KEY_URI, GOOGLE_APPLICATION_CREDENTIALS, APP_PORT, DB_PATH, CORS_ORIGINS, ENCRYPTION_MODE
